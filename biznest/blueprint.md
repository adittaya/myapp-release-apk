
# BizNest Application Blueprint

## Overview

BizNest is a Flutter-based application designed to streamline business operations. This document outlines the project's architecture, features, and design principles.

## Current Features & Design

### Initial Setup and Authentication

- **Firebase Integration:** The project is connected to a Firebase backend for services like authentication.
- **Authentication:**
    - **Google Sign-In:** Users can authenticate using their Google accounts.
    - **Auth Flow:** The application correctly handles the user's authentication state, showing a login screen to unauthenticated users and the home screen to authenticated users.
- **Theming:**
    - A basic Material 3 theme is in place with both light and dark modes.
    - The `google_fonts` package is used for custom typography (`Oswald`, `Roboto`, `Open Sans`).
